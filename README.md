# Medellín: Aranjuez

Juego de mundo abierto en tercera persona inspirado en el barrio Aranjuez
(Comuna 4, Medellín).

- [`medellin-aranjuez/`](medellin-aranjuez/README.md): el juego, un MVP para
  escritorio Windows 11 hecho con Three.js (WebGL 2) y empaquetado con
  Electron.
- [`medellin-unreal/`](medellin-unreal/LEEME.md): el proyecto de Unreal
  Engine 5 para seguirlo en ese motor, con el mundo importado desde el juego.
  El plan del traspaso está en
  [`medellin-unreal/TRASPASO.md`](medellin-unreal/TRASPASO.md).
